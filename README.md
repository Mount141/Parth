# Raksha Bandhan Surprise 🎀

A small mobile-friendly Raksha Bandhan surprise website made with plain HTML, CSS and JavaScript.

## GitHub Pages setup

1. Create a new GitHub repository, for example `rakhi-surprise`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish it.
7. Send your sister the generated `github.io` link.

## Personalize it

- Change the jokes directly in `index.html`.
- Replace the photo placeholders with your own photos.
- Change the final message to an inside joke between you and your sister.
- If you want music, add an audio file and an audio element to `index.html`.

The design uses an original playful cartoon/emoji style rather than reproducing copyrighted Shinchan artwork.
